# Калькулятор

Лёгкий калькулятор для Windows 11 в стиле системного: скруглённые кнопки, светлая и тёмная тема (следует за настройками Windows), русский интерфейс, работа с клавиатуры. Исполняемый файл — около 40 КБ, не требует установки .NET (используется .NET Framework 4.8, встроенный в Windows 10/11).

## Возможности

- `+ − × ÷`, `%`, `√x`, `x²`, `1/x`, `±`, `⌫`, `CE`, `C`
- Точная десятичная арифметика (`0,1 + 0,2 = 0,3`), повтор операции по `=`
- Журнал вычислений (кнопка с часами или `Ctrl+H`): последние 100 примеров, клик по записи возвращает результат на дисплей, кнопка «Очистить»
- Память: `MC`, `MR`, `M+`, `M−`, `MS` (компактная строка над кнопками) и индикатор «M» на дисплее; горячие клавиши `Ctrl+L`, `Ctrl+R`, `Ctrl+P`, `Ctrl+Q`, `Ctrl+M`
- Кнопка-булавка (`Ctrl+T`): окно поверх всех остальных
- Запоминает положение и размер окна, состояние булавки и журнала между запусками (файл `%AppData%\Calculator\settings.ini`)
- Буфер обмена: `Ctrl+C` копирует число, `Ctrl+V` вставляет (понимает `1 234,5`, `1,234.56`, `-7`); то же в контекстном меню дисплея
- Контекстное меню записи журнала (правая кнопка): копировать результат, копировать пример целиком, удалить запись
- Инженерный режим (кнопка `f(x)`, `Ctrl+2`; обычный режим — `Ctrl+1`): скобки, `sin cos tan` и обратные (`2nd`), `ln`, `log`, `eˣ`, `10ˣ`, `xʸ`, `n!`, `|x|`, `∛x`, `mod`, `π`, `e`; углы в градусах, радианах и градах (кнопка `DEG`); неявное умножение (`2π`, `3(4+5)`); точные значения на четвертях оборота (`sin(180) = 0`)
- Журнал, память, буфер обмена и запоминание режима работают и в инженерном режиме
- Клавиатура: цифры, `+ - * /`, `Enter`/`=`, `,`/`.`, `%`, `Backspace`, `Esc` (C), `Del` (CE), `Ctrl+C` (копировать результат)
- Тема и цвет заголовка окна подстраиваются под систему

## Сборка

Нужен только Windows 10/11 (используется компилятор `csc.exe`, поставляемый с Windows).

```powershell
.\build.ps1             # -> build\Calculator.exe
.\build-installer.ps1   # -> dist\Calculator-Setup-<версия>.exe (нужен Inno Setup 6)
```

Тесты логики:

```powershell
.\tests\run-tests.ps1
```

## Установщик

Собирается из `installer\setup.iss` ([Inno Setup 6](https://jrsoftware.org/isinfo.php)). Страницы мастера: лицензионное соглашение → выбор папки установки → выбор папки в меню «Пуск» → ярлыки (рабочий стол / «Пуск») → установка. Есть деинсталлятор; можно ставить «только для меня» (без прав администратора) или «для всех пользователей».

## Структура

```
src/           исходники: Engine.cs (обычный режим), Expr.cs (вычислитель выражений),
               SciEngine.cs (ввод в инженерном режиме), Settings.cs, MainForm.cs (интерфейс)
tests/         тесты логики
installer/     сценарий Inno Setup и текст лицензионного соглашения
assets/        иконка
tools/         генератор иконки
```
