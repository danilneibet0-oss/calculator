# Калькулятор: список улучшений

Состояние на версию 1.3.0 (проверено по исходникам). Тесты (`tests\run-tests.ps1`) на момент анализа проходили.

## Важное

- [x] **Доступность с клавиатуры.** Кнопки `CalcButton` невыбираемые (`Selectable = false`, `TabStop = false`): Tab по ним не ходит, программы для чтения с экрана не видят имён. Нужны `AccessibleName` и выбор кнопок с фокусом с понятной подсветкой.
- [ ] **Перерисовка создаёт шрифты и пути каждый раз.** В `CalcButton`, `DisplayBox` и `HistoryList` на каждой перерисовке создаются `new Font(...)` и `GraphicsPath` (`MainForm.cs`, строки около 149–172, 264–280, 353–374). Шрифты кешировать, пересоздавать только при смене темы или DPI.
- [ ] **Память разделена между двумя движками с обходными путями.** В `MainForm.SciMemory` значение из инженерного режима передаётся через `engine.Paste(...)`, а `MR` вызывает `engine.MemoryRecall()` и затем `sci.Paste(engine.CopyText)`. Вынести память в отдельный класс, который используют оба режима.

## Структура

- [ ] **`MainForm.cs` на ~1080 строк.** Разбить: кнопки, дисплей и журнал в отдельные файлы (`Controls/`), тема в `Theme.cs`.
- [ ] **Версия задаётся в нескольких местах:** `Program.cs` (`1.3.0.0`), `installer\setup.iss` (`AppVersion`), `CHANGELOG.md`. Держать версию в одном месте, например в `version.txt`, который читают сборка и установщик.
- [ ] **Два вычислителя с разными типами.** `CalcEngine` работает на `decimal`, `Expr` на `double`. Проверить округления на больших числах и степенях, а также перенос результата между режимами (`SciMemory` с `(decimal)value`).

## Качество и тесты

- [ ] **UI не тестируется.** `run-tests.ps1` исключает `MainForm.cs` и `Program.cs`. Не покрыты горячие клавиши, переключение режимов и сохранение окна. Таблицу горячих клавиш можно вынести в отдельный класс и протестировать.
- [ ] **Строки захардкожены по-русски.** Для английского интерфейса понадобится `.resx` или словарь строк.
- [ ] **Невидимые символы в исходниках.** В `Engine.cs` (строка 232, `TryParseNumber`) несколько похожих пробельных символов, в `MainForm.cs` (строка 161, диапазон иконок) символы, которые не видны в выводе. Заменить на явные escape-последовательности (`\u00A0`, `\uE000`). В начале `MainForm.cs` есть BOM — он безвреден.
- [ ] **Нет CI.** Тесты запускаются вручную, папки `.github/workflows` нет. Добавить GitHub Actions с `run-tests.ps1` на `windows-latest`.

## Документация

- [ ] **README пишет «для Windows 11»** (строка 3), а сборка и установщик работают и на Windows 10. Уточнить формулировку. То же в `Program.cs` (`AssemblyDescription`) и `CHANGELOG.md` (первый выпуск).
- [ ] **CHANGELOG без раздела «Unreleased».** Добавить его для следующих версий.
